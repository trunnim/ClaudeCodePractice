# practice/

Scratch space for lesson exercises. Everything you produce while working through the course lands here.

`make progress` looks in this directory: a lesson that declares `artifact: practice/<file>` shows as done
once that file exists.

This directory is exempt from the link, import and budget checks in `make docs` — see `LINK_CHECK_EXEMPT` in
`tools/check_docs.py`. Your notes can be as rough as you like, and Track C's sample repositories can be as
broken as they need to be.

Commit your work here if you want a record of your progress. Nothing depends on it being clean.
